# Micro_Maas

## Clone

```bash
git clone https://github.com/RakhulJM/Micro_Maas.git
cd Micro_Maas
```

## Virtual Environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Windows:

```bash
.venv\Scripts\activate
```

## Dependencies

```bash
pip install pandas networkx geopy
```

## Run

### Graph Router

```bash
python3 ad_router.py
```

### Route Calculator

```bash
python3 router.py
```

## Deactivate

```bash
deactivate
```
