# Micro_Maas

## Clone

```bash
git clone https://github.com/ATITYARAM/Micro_Maas.git
cd Micro_Maas
```

## Python Environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Windows:

```powershell
.venv\Scripts\activate
```

## Python Dependencies

```bash
pip install pandas networkx geopy
```

## Astro

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

Preview:

```bash
npm run preview
```

## Terrain map

Download the fixed 1 km terrain tiles:

```bash
npm run terrain:download
```
